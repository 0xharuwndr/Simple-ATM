# Simple ATM System

A lightweight, terminal-based ATM simulator that models fundamental banking operations, user authentication, and transaction handling.

---

## 🚀 Features

- **User Authentication**: Secure account login using account numbers and PIN validation.
- **Balance Inquiry**: View real-time account balance updates.
- **Deposits**: Deposit funds with real-time balance calculations.
- **Withdrawals**: Withdraw funds with built-in validation for insufficient balance.
- **Transaction History**: Track recent activity and receipts (if enabled).

---

## 🛠️ Getting Started

### Prerequisites

Ensure you have Git and the appropriate language runtime installed on your machine (e.g., Python, Java, or C++ depending on your implementation).

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/0xharuwndr/Simple-ATM.git
   cd Simple-ATM
   ```

2. **Run the Application:**

   *If written in Python:*
   ```bash
   python main.py
   ```

   *If written in Java:*
   ```bash
   javac Main.java
   java Main
   ```

   *If written in C++:*
   ```bash
   g++ main.cpp -o atm
   ./atm
   ```
